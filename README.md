# Detection Engineering: Sysmon Tuning & Wazuh Integration

## Overview
This project focuses on optimizing Sysmon event logging and integrating telemetry into Splunk for monitoring and alerting. It demonstrates my ability to tune noisy data, improve signal quality, and build detection‑ready visibility across endpoints.

## Objectives
- Deploy and configure Sysmon with a tuned configuration
- Reduce noise while preserving high-value security events
- Integrate Sysmon logs into Splunk for centralized monitoring
- Validate detections and ensure alert fidelity

## Tools & Technologies
- Sysmon (System Monitor)
- Splunk SIEM
- Windows Event Viewer
- YAML configuration files

## Project Workflow
1. **Baseline Logging Review** – Identified noisy or redundant event IDs.
2. **Sysmon Configuration Tuning** – Applied filters to reduce noise and highlight meaningful activity.
3. **Wazuh Integration** – Forwarded Sysmon logs to Wazuh for analysis.
4. **Detection Validation** – Triggered test events to confirm alerting accuracy.
5. **Refinement** – Adjusted filters to balance visibility and noise reduction.

## Key Improvements
- Reduced unnecessary event volume
- Increased clarity of endpoint activity
- Improved detection fidelity in Splunk

## What I Learned
- How to tune Sysmon for real-world detection engineering
- How to integrate endpoint telemetry into a SIEM
- How to validate and refine detection logic
